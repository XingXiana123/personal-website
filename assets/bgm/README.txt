========================================================
 背景音乐放这里（v3.6）
========================================================

【一句话】把你想要的音乐文件改名成  bgm.mp3  放进这个文件夹，
          刷新页面就会自动播放；不想播了，点右上角音符按钮关掉。

--------------------------------------------------------
 1. 文件放哪、叫什么
--------------------------------------------------------
必须放在这个文件夹（assets/bgm/），文件名必须是下面三个之一：

    bgm.mp3     ← 首选，就用这个
    bgm.ogg     ← 备选（部分老浏览器 / 开源场景）
    bgm.m4a     ← 备选（Safari 的退路）

- 三个里放一个就够。放了多个时，浏览器从 mp3 开始试，哪个能播用哪个。
- 名字必须严格是 bgm.mp3（小写、不要空格、不要中文、不要 (1) 这种后缀）。
- 不要用 .wav / .flac：前者太大，后者 Safari 不支持。

--------------------------------------------------------
 2. 一个都没放会怎样？
--------------------------------------------------------
不会报错、不会弹窗：音符按钮自己隐藏，其它功能一切照常。
（判断逻辑见 js/script.js 的 initBgmToggle 里的 markMissing：
  6 秒内读不出音频就当作"没放"，只在浏览器控制台留一句 info。）

--------------------------------------------------------
 3. 音量、循环、自动播放
--------------------------------------------------------
- 循环：代码里写死了循环播放（<audio ... loop>），不用管。
- 音量：默认 0.4（刚好的"背景"音量，不会盖住点击音效）。
  想改就改 js/script.js 里 initBgmToggle 的  BGM_VOLUME = 0.4  这个数。
- 自动播放：进站自动播。但浏览器有"没跟页面交互过不许出声"的策略，
  所以第一次打开很可能被拦下 —— 这时页面右下角会提示
  "点一下任意位置，开始播放背景音乐"，你随手点一下就放起来了，
  之后浏览器会记住这个站，不再拦。
- 手机端：按钮挪到左下角小猫的上面（桌面端在右上角音效钮下面）。

--------------------------------------------------------
 4. 关于版权
--------------------------------------------------------
这是要公开给所有人看的个人主页，请用自己录的、自己做的，
或者明确允许免费使用的音乐（如 CC0 / 公共领域素材站）。
别放有版权的流行歌曲 —— 网站在别人的服务器上，
被投诉下架的是你自己的主页。

--------------------------------------------------------
 5. 换歌 / 临时试听
--------------------------------------------------------
- 换歌：直接替换文件、保持文件名不变即可（记得刷新页面，浏览器有缓存）。
- 临时试听别的音源（不改文件、不改代码）：
  在网址后面加  ?bgm=完整网址  例如
      index.html?bgm=https://example.com/test-song.mp3
